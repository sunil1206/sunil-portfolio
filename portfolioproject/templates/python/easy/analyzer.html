Min, Max, and Sort

This tool accepts a list of numbers and calculates the minimum value, maximum value, and a sorted version of the list **without using Python's built-in functions** for those specific tasks.

Custom Calculation Logic

The following functions are used on the server to perform the analysis from scratch.


# Finds the maximum value in a list
def find_max(number_list):
    max_value = number_list[0]
    for number in number_list[1:]:
        if number > max_value:
            max_value = number
    return max_value

# Finds the minimum value in a list
def find_min(number_list):
    min_value = number_list[0]
    for number in number_list[1:]:
        if number < min_value:
            min_value = number
    return min_value

# Sorts a list using the bubble sort algorithm
def bubble_sort(number_list):
    length = len(number_list)
    for i in range(length - 1):
        for j in range(0, length - i - 1):
            if number_list[j] > number_list[j+1]:
                # Swap elements
                temp = number_list[j]
                number_list[j] = number_list[j+1]
                number_list[j+1] = temp
    return number_list
